# dither-ts

Open source dithering experiment in TypeScript.

## Install

```sh
npm install
npm --prefix app install
npm --prefix electron install
```

## Web app (hot reload)

```sh
npm run dev
```

Open http://localhost:5173

## Desktop app

```sh
npm run desktop
```

## Tests

```sh
npm test
npm --prefix app test -- --run
```
